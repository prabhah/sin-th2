# SIN-TH2 Web

一个用于 SIN-TH2 温湿度记录仪的轻量级 Go Web 管理工具。服务通过串口直接读取设备数据，并在浏览器中展示实时温湿度、设备状态和历史曲线。

## 功能

- 读取设备型号、设备时间、记录间隔和历史记录数量
- 每 10 秒自动刷新当前温湿度及设备状态
- 默认加载最近 60 条历史记录（5 分钟间隔时约为最近 5 小时）
- 滚动到底部时按每批 60 条继续加载更早的数据
- 使用双坐标曲线展示历史温度和湿度
- 将全部历史记录下载为 UTF-8 CSV 文件
- 前端温湿度修正：
  - 默认温度修正：`-2.6 °C`
  - 默认湿度修正：`-14.8 %RH`
  - 配置保存在浏览器 `localStorage` 和 Cookie 中
  - 修正仅影响页面显示和下载的 CSV，不修改设备原始数据
- 将设备时间设置为电脑当前时间（两次确认）

## 已确认的设备协议

- 串口：`57600 8N1`
- CRC：CRC16/Modbus（`0xA001`），低字节在前
- `0x10`：读取型号/版本；实机返回 `TH2MV202`
- `0x12`：读取 98 字节配置
  - 前 6 字节：年（自 2000 起）/月/日/时/分/秒
  - `[72:75]`：记录间隔（时/分/秒）
- `0x13`：读取历史记录
  - 请求包含 32 位大端起始位置和 8 位记录数
  - 每次最多读取 60 条
  - 每条记录 8 字节，最后 4 字节为大端温度和湿度，数值除以 10
- `0x15`：读取当前温湿度
- `0x17`：读取历史元数据，包括最后采样时间和记录数量
- `0x11`：写入完整配置

历史时间轴根据 `0x17 word[1]` 的最后采样 Unix 时间和 `0x12` 的固定采样间隔重建。Unix 时间按 UTC 解释。

> [!WARNING]
> 使用 `0x11` 写入配置会清空设备中的全部历史记录。网页中的“设置为电脑当前时间”操作会要求连续确认两次，并同时将记录间隔设为 5 分钟。

## 环境要求

- Go 1.22 或更高版本
- macOS、Linux 或其他可访问串口的系统
- 已连接的 SIN-TH2 设备
- 服务进程对串口设备具有读写权限

## 运行

先确认设备对应的串口。macOS 中通常可以使用：

```bash
ls /dev/cu.*
```

安装依赖并启动：

```bash
go mod download
go run . -port /dev/cu.usbserial-10
```

然后打开：

```text
http://127.0.0.1:8080
```

可以通过 `-listen` 修改监听地址：

```bash
go run . -port /dev/cu.usbserial-10 -listen 0.0.0.0:8080
```

如果需要编译独立程序：

```bash
go build -o sin-th2-web .
./sin-th2-web -port /dev/cu.usbserial-10
```

## HTTP 接口

| 接口 | 方法 | 用途 |
| --- | --- | --- |
| `/api/meta` | `GET` | 设备型号、时间、记录间隔和记录数量 |
| `/api/current` | `GET` | 当前温湿度 |
| `/api/records?start=0&count=60` | `GET` | 读取指定范围的历史记录，`count` 最大为 60 |
| `/api/records.csv` | `GET` | 读取并下载全部原始历史记录 |
| `/api/sync-time` | `POST` | 设置设备时间和 5 分钟记录间隔；会清空历史记录 |

CSV 按钮会在浏览器端应用当前温湿度修正值后再下载文件。

## 注意事项

- 服务必须独占串口；请勿同时运行其他串口探测脚本、`screen` 或原厂 DataRead。
- 默认仅监听 `127.0.0.1`，不会暴露到局域网。
- 修改监听地址为 `0.0.0.0` 前，请自行配置访问控制和防火墙。
- 温湿度修正值只保存在当前浏览器中，不会写回设备。
